# 岔路书签

一个为扫描版游戏书准备的本地 PDF 阅读工具。它不做 OCR，而是在 PDF 外维护页码偏移、节点、跳转关系、标记、备注和阅读历史。

## 使用

1. 双击 `index.html`，建议使用最新版 Chrome、Edge 或 Safari。
2. 点击“选择 PDF”打开扫描版 PDF。
3. 在右侧设置页码偏移。例如书中第 1 页是阅读页第 7 页，偏移就是 `6`。
4. 添加节点。节点编号默认使用当前书中页码；固定阅读页留空时，会自动使用“书中页码 + 偏移”。
5. 点击节点只会选中并显示资料，不会改变 PDF；需要阅读该节点时，再点击节点旁或资料卡上的“跳转”。
6. 通过“添加关系”维护选择分支；目标节点可按编号、名称、标签、备注或书中页码搜索。点击“关系图”查看、缩放整个非线性路线。

节点可以独立标记为“结局节点”和“已经走过”。结局属性可以与重要、线索、危险等内容标记共存；明确跳转到节点时会自动记录为已走过，单击节点查看资料不会改变进度。两项状态也可以在节点编辑窗口或“更多”菜单中手动调整。

关系图默认以 `100%` 打开，保持文字清晰。`−` 和 `+` 分别缩小、放大关系图，中间会显示当前比例；“显示全部”会自动计算比例，让所有节点完整进入当前可视区域。

删除节点时，先选中节点，再点击资料卡上的“更多 → 删除节点”。确认后，与该节点相连的跳转关系也会移除；底部提示条可立即撤销删除。

节点、关系、备注和阅读历史会按 PDF 的完整文件名分别保存在浏览器本地，并在每次修改后自动保存。再次选择同名 PDF 时会自动加载对应书签。由于浏览器安全限制，工具不能静默地在原 PDF 旁创建 JSON 文件；重新打开页面后仍需手动选择一次 PDF，但书签数据不会丢失。

## 输入跳转规则

- 输入内容与现有节点编号完全相同：跳转到该节点。
- 输入一个没有对应节点的数字：把它当作书中页码，并应用偏移。
- “上一页/下一页”控制的是 PDF 实际页面。
- 左上方回溯按钮返回最近一次跳转前的位置。
- `− / +` 控制页面缩放；初始状态会自动适合可用区域。
- 工具栏中的侧栏按钮可隐藏节点面板，让 PDF 占满窗口。
- 节点列表和关系图中的节点都采用“先选中、后跳转”，以免查看备注时意外换页。

## 数据备份

右上角“数据”菜单可以导出或导入 JSON。“清空当前书籍数据”只影响当前文件名对应的数据，不影响其他书。更换浏览器或清理浏览器数据前，建议先导出备份。

PDF 文件只在本机浏览器中打开，不会上传。导出的 JSON 只包含文件名、节点、跳转关系、标记、备注和历史，不包含 PDF 内容。

## 自带示例

目录中包含：

- `示例游戏书-雾林钟塔-扫描版.pdf`：8 页纯图片 PDF，前两页是封面和说明。
- `示例书签数据-雾林钟塔.json`：6 个节点及其跳转关系、标记和备注。

先选择示例 PDF，再从“数据 → 导入书签数据”导入 JSON。示例偏移已经设置为 `2`，节点 1 会显示在阅读页第 3 页。

## 键盘操作

按 `?` 可以随时打开完整快捷键表。最常用的纯键盘阅读流程是：

- `← / ↑ / PageUp / Shift + Space`：上一阅读页；`→ / ↓ / PageDown / Space`：下一阅读页。
- `1–9 / 0`：直接执行选中节点卡片的第 1–10 个选项。可用数字会显示在选项按钮上。
- `G` 或 `Ctrl/Cmd + K`：聚焦跳转输入框，输入节点编号或书中页码后按 `Enter`。
- `B` 或 `Alt + ←`：回溯上一个阅读位置；`J`：跳转到选中的节点。
- `/`：搜索节点；在关系图打开时搜索图中节点，`Enter` 选中首个匹配节点。
- `N / E / C`：添加节点、编辑节点、添加关系。表单内用 `Enter / Shift + Enter` 前进或后退，按 `Ctrl/Cmd + Enter` 保存；备注框中的普通 `Enter` 仍然换行。
- `V / Shift + E`：切换“已经走过”与“结局节点”。
- `M / S / F`：打开关系图、切换侧栏、切换全屏；`+ / −` 控制缩放。
- `Esc`：关闭当前菜单、表单或弹窗；`O`：选择 PDF。

光标位于输入框、文本框或下拉框中时，单字母和数字键仍用于正常输入，不会触发阅读快捷键。关系图打开后会自动聚焦并居中当前阅读节点；用方向键按空间位置选择相邻节点，`Home / End` 选择首个 / 末个节点，`/` 搜索，`+ / −` 缩放，`0` 显示全部，`J` 跳转到选中节点。

## 浏览器说明

本工具内置 PDF.js 5.7.284，直接把指定页面绘制到 Canvas，不再依赖浏览器自带 PDF 插件。同时内置 JBIG2、JPEG 2000 和色彩管理所需的 WASM 资源，用于兼容黑白扫描书和其他特殊图像编码；直接双击 `index.html` 离线使用时也能读取 JBIG2 和 JPEG 2000 页面。PDF.js 及其许可证位于 `vendor/` 目录。

阅读器会自动识别由多个扫描碎片和一张完整组合页构成的异常页组，只保留最终的完整页面；碎片不会进入阅读页总数、连续翻页、书中页码偏移或节点定位。关系图会直接在连线上显示已有的“选项文字”，不会增加额外的关系字段。

更新 `vendor/pdfjs-wasm/` 中的解码文件后，运行 `node generate-wasm-data.mjs` 可重新生成双击模式使用的内嵌数据。
